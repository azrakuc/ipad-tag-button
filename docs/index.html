        元のデータをすべて表示

        登録したタグをボタン（カード）で組み合わせてプロンプトを作り、コピーして Draw Things などに貼り付けるアプリです。見出しをタップすると開閉します。

        プロンプトを作る（作成タブ）
        1. 下のカテゴリーボタンで、カテゴリーを選びます。
        2. カードをタップすると、そのカードのタグが右（縦画面では下）の「選択中のタグ」に集まります。もう一度タップすると外れます。
        3. カードを長押しすると、タグの内容を表示します。
        4. タグの「×」で 1 つずつ削除できます。「並べ替え」でドラッグして順番を変えられます。「クリア」はすべて消します（直後に「元に戻す」が出ます）。
        5. 「コピー」を押して、Draw Things などに貼り付けます。iPad の Split View で並べると、行き来せずに貼り付けられます。

        同じタグは重複せず、1 つだけ入ります。コピーするときの区切り文字は、管理タブの「設定」で変えられます。

        タグを登録する（管理タブ）
        • タグは、カテゴリー ＞ グループ ＞ タグ の 3 段で整理します（例：カテゴリー「キャラ」、グループ「衣装」、タグ「ウェイトレス」）。
        • それぞれの「＋ 追加」で作り、「編集」で名前の変更や削除ができます。タグの編集では、内容（カンマか改行で区切る）、サムネイル、移動、複製もできます。
        • 左の「☰」をつかんで上下にドラッグすると、同じ階層の中で並べ替えられます。
        • カテゴリーやグループを削除すると、中のタグもまとめて消えます。
        長いプロンプトから切り出して登録する（管理タブ）
        1. 上のリストで、登録先のカテゴリーとグループを選びます。
        2. 「① 元のプロンプト」に、長いプロンプトを貼り付けます（画像から読み込むこともできます）。
        3. 「② チップ」に、タグごとに分かれて並びます。使いたいチップをタップすると、「③ 新しいタグ」の内容に入ります。もう一度タップすると外れます。薄いチップは、登録済みのタグに含まれています。
        4. 名前を入れて「登録」を押します。①の文章は残るので、続けて次のタグを切り出せます。

        文章形式のプロンプトは、プルダウンの「分け方」を「文で分ける」にすると、文ごとのチップになります。「既存のタグに追記」で、すでにあるタグに足すこともできます。

        画像からプロンプトを取り出す（画像タブ）
        • 「画像を選ぶ」か、Split View から画像をドロップします。PNG・JPEG・WebP に対応しています。
        • Draw Things、A1111 / Forge、ComfyUI、NovelAI で作った画像から、ポジティブ・ネガティブ・設定を取り出します。
        • 「コピー」、「作業欄に追加」（作成タブに入れる）、「管理で切り出す」（登録の元にする）ができます。
        • 画像は、この端末の中で読むだけです。送信も保存もしません。

        写真アプリを経由した画像は、プロンプトの情報が消えていることがあります。「ファイル」アプリに保存した元の画像を選んでください。

        ホーム画面への追加とバックアップ
        • Safari の共有ボタン →「ホーム画面に追加」で、アプリのように使えます。追加しないと、しばらく使わないときに、Safari が登録データを消すことがあります。
        • 登録したデータは、この端末の中だけに保存されます。端末の変更や、データが消えたときに備えて、管理タブの「エクスポート」で、定期的に JSON ファイルを保存してください。「インポート」で戻せます。
        • 「新しい版があります」と出たら、「更新する」を押してください。
        プライバシー
        • 登録したデータと、読み込んだ画像・プロンプトは、この端末の外に送りません。
        • 使われているかを知るため、アクセス解析（GoatCounter）で、「ページを開いた」という情報だけを数えています。Cookie は使わず、タグや画像などの内容は送りません。
        • 画面上部の「Ko-fi」は、押したときだけ外部のサイトを開くリンクです。
        支援について

        このアプリは無料で使えます。役に立ったと思ったら、Ko-fi から支援してもらえると、開発を続ける励みになります。支援は任意で、支援しなくても、すべての機能を使えます。
